# moba-arpg-ideas

Ideas and concepts for the MOBA (game: `moba-arpg-game`, backend: `moba-arpg-backend`): proposals, sketches, diagrams and design notes, before anything gets built. Nothing here is final; it's the place to collect and discuss ideas.

## Folders

They follow the Discord channels:

| Folder | For |
|---|---|
| [heroes](heroes/) | Hero concepts: passives, ultimates, ascension paths, identity |
| [spells-and-mods](spells-and-mods/) | Shop spells, mods, how they combine |
| [maps-and-layouts](maps-and-layouts/) | Map layouts, lanes, zones, objectives |
| [items-and-economy](items-and-economy/) | Items, prices, gold and XP |
| [game-mechanics](game-mechanics/) | Systems that span several areas (damage types, affinities, combat rules) |

## Adding an idea

- One folder per idea inside the matching category, e.g. `game-mechanics/spell-affinity/`.
- Give it a `README.md`: what the idea is, why, open questions, and a link to the Discord discussion if there is one.
- Put images, sketches and their source files next to it.
- If an idea fits several categories, put it in `game-mechanics`.

Commits go straight to `main` here (no dev branch or PRs).
